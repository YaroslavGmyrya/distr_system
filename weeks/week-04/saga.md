# Диаграмма Saga

Построим SAGA events-s06 из 4-ех шагов:

Создание заказа -> резервирование товара -> оплата -> доставка.

Компенсации для каждого шага:

* Создание заказа : удаление из БД записи о заказе.

* Резервирование товара : "вернуть" зарезервированный товар на склад или в магазин (инкрементировать кол-во товаров этого типа в БД), инициировать откат на предыдущем шаге.

* Оплата : Удалить из местной БД контекст оплаты. Инициировать откат на предыдущих сервисах (отправить какое-то сообщение на сервис "Резервирование"). 

* Доставка : Самый сложный случай. Если оплата была произведена, то нужно как-то общаться с банком для отката операции у банка. Инициировать откат предыдущих шагов.
